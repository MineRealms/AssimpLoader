# Rendering Integration Contract

Rendering owner is implementing:

- `render.ModelTextureCache.getTexture(AssimpScene scene, AssimpMesh mesh)` -> ResourceLocation, shared lazy per-scene/per-material texture resolution.
- `render.ModelTextureCache.getEmbeddedTexture(AssimpScene scene, int index)` -> ResourceLocation or null.
- `render.ModelTextureCache.clear()` -> release owned dynamic textures, render thread only.
- `render.SceneTransforms` -> cached scene bind node transforms/bounds; dynamic rendering traverses hierarchy rather than treating local vertex data as world coordinates.
- `render.AssimpBakedModel(AssimpScene, TextureAtlasSprite, ResourceLocation, ItemTransforms)` new constructor; existing three-arg constructor retained. Loading owner: pass `context.getTransforms()` in the bake call to honor resource JSON display transforms.
- `render.ClientRenderResources.clear()` -> release owned rendering caches and reset ClientAnimationManager; safe scheduling to render thread. Core reload hooks can invoke it from client event code without coupling common loader to client classes. Rendering owner will install client resource reload/logout/shutdown listeners.

LookDev may use its own preview-only GPU buffers and texture decoder initially, but should use the shared `ModelTextureCache` API above for one texture decode across preview/world/item. Source resource location is available via `AssimpScene.getSourceResource()` (loading owner), source filesystem via getSourcePath().

Parent owns skeleton/source weight extraction; rendering owner selects strongest four weights at upload and will not modify BoneHierarchyBuilder/AnimationPlayer/AnimationState.

Implementation status: APIs above now exist. `rendering.CachedMeshRenderer` caches immutable static/node mesh VAO/VBO/EBO on the render thread, uses Minecraft lightmap/overlay textures and restores its touched bindings. The Oculus path below handles opaque Showcase and armored-car entity geometry; other shader-pack callers and transparent meshes retain the vanilla batch path. Skinned meshes use the shared GPU skinning renderer or a palette-cached CPU fallback, preserving animation with shaders/GPU disabled. `CpuSkinning` cache weakly owns instance animation state and recomputes only when AnimationState publishes a new palette. Resource lifecycle clears all these caches.

## Oculus Extended Vertex Cache

`OculusEntityBufferCache` builds local mesh data through a normal TRIANGLES/NEW_ENTITY `BufferBuilder` once. Oculus adds entity IDs, mid UVs and tangents before the resulting expanded ENTITY buffer is uploaded into a persistent Minecraft `VertexBuffer`. Draws continue through Minecraft's active shader instance, render type and `drawWithShader`, preserving Oculus sampler, framebuffer, shadow and tessellation handling. No custom GLSL program bypasses the shader pack.

Local geometry is immutable; dynamic scene-node transforms can still animate wheels. Overlay/light/entity attributes on the cache's private VAO use fresh per-draw constants instead of the first instance's baked values. The layout is checked against the exact runtime Oculus ENTITY format. The bridge scopes the appropriate entity/block-entity phase and restores the preceding phase. Reload/generation/logout/shutdown release buffers, and format changes cause an upload again. Failures log once and use the ordinary geometry path until reload. GUI/item/preview and skinned or transparent geometry do not enter this cache.

Immediate draw boundaries clear Oculus uniform/sampler listeners and its last-applied shader before switching materials. Program restoration also synchronizes Oculus' `_glUseProgram` cache through `ProgramManager`, in addition to the raw GL restoration used by the custom GPU paths. Restoring only the raw program caused stale software state and GL uniform errors in the first runtime attempts; the corrected run completed without those errors.

`statistics()` reports buffer count, cumulative uploads/bytes/vertices and entity/shadow draws for explicit diagnostics. These counters demonstrate buffer reuse; they are not an FPS benchmark. The actual installed Oculus 1.8.0 bytecode was checked for the extended format, BufferBuilder tangent path, render phases and Minecraft VertexBuffer integration. Compatibility with unrelated shader packs still requires runtime checks.

ClientRenderResources installs reload, logout, shutdown event listeners and checks loader cache generation once per scene render. Loader should still clear the model registry at reload start; renderer cleanup does not remove loaded source models. AssimpBakedModel now receives ItemTransforms and uploads no embedded images during baking. LookDev should acquire its texture ID through Minecraft TextureManager for ModelTextureCache.getTexture(scene,mesh), and must not release those shared IDs.
