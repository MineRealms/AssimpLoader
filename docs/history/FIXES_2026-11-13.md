## 本轮结果

- LookDev 入口改为已加载模型预览器：列表、筛选、旋转、平移、缩放、适配和复位；支持全部缓存场景，节点页留空。
- 预览使用缓存 VBO/EBO 直接绘制，移除当前入口的逐帧像素回读、图像复制和日志输出。世界/物品的静态几何也使用 GPU 缓存，光影包/透明/不支持场景保留原版提交，蒙皮有 CPU 回退。
- 修复 FBX 文件单位、完整节点层级和物品尺寸；默认根据场景包围盒适配，JSON display transforms 可随资源重载更新。
- 模型标识、后台导入、资源包侧文件、覆盖文件删除恢复和 GPU/贴图清理统一接入生命周期。
- 测试、实际截图和资源重载中发现的问题继续修正，未以“能编译”代替画面验证。

## 测试中继续修复

第一次完成生产/测试编译后运行 124 项测试，2 项失败：OBJ 材质 alpha 与 FBX 实际尺寸。负责人补回材质修复及 5 项回归测试；主线根据打包原生库记录的 Assimp revision 核对内置单位换算，加入 FBX/GLB 尺寸对照。随后 129 项全部通过。

## 复现

```powershell
.\gradlew.bat test build --console=plain --no-daemon --no-parallel
.\gradlew.bat runClient "-PclientSmokeWorld=New World" --console=plain --no-daemon --no-parallel
.\gradlew.bat runClient -PwithoutOptionalMods -PclientStartupSmoke --console=plain --no-daemon --no-parallel
git diff --check
```

第二条要求 `run/saves/New World` 已存在；它只在显式传参时启动测试和截图。常规使用 `runClient`，世界内按 `L` 或 `/lookdev`。`F3+T` 走 Minecraft 资源重载，外部覆盖文件可用客户端 `/assimploader reload`；Java 修改需要重启。

## 当前边界

节点页留空、任意文件导入、路径追踪、真实 shader 注入及 Gaussian 世界入口均未作为首轮修复的新功能实现。首轮尚无动态 PBR loader；后续已实现嵌入/磁盘/资源图像的材质级 PBR，并使用 Oculus 进行光影开关与重载检查，见[当前使用](../guides/OCULUS_PBR_USAGE.md)和[后续实机验收](PBR_VALIDATION_2026-11-13.md)。上文构建时间、测试数和 jar hash 仅属于首轮快照。复杂透明表面尚无逐像素排序。
