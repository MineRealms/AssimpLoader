# LookDev 模型预览

2026-11-13：LookDev 当前入口改为 Minecraft 原生 Screen，用于查看 AssimpLoader 已加载的模型。节点编辑器标签页保留空白，不执行旧节点图、材质修改或 shader 注入流程。

## 入口和内容

- 游戏中按绑定的 `L`，或使用客户端命令 `/lookdev`。
- 左侧列出缓存内所有场景，别名指向同一个 scene 时只显示一项；不同导入模式的不同 scene 分别显示。
- 搜索框筛选模型名，列表支持滚轮；完整资源名在悬停时显示。
- 预览保留导入的节点层级、实例和局部变换；STATIC 数据按已烘焙坐标绘制。当前显示绑定/静止姿态，不播放动画。
- 显示网格数、三角面数、嵌入图像数及包围盒尺寸。模型切换后自动居中并适应视口。
- 列表每秒检查一次当前缓存，替换或删除的 scene 会使旧预览资源失效；预览不会自行重新导入文件。

## 视角操作

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 绕模型旋转 |
| 右键、中键或 Shift+左键拖动 | 按相机平面平移 |
| 预览内滚轮、`+`/`-` 按钮 | 按距离比例缩放 |
| Fit / `F` | 居中并适应当前视口，保留观察角度 |
| Reset / `R` | 恢复默认观察角度并适应视口 |
| Esc / 关闭按钮 | 返回游戏并释放预览资源 |

## 绘制与性能

旧预览每次将帧缓冲 `glReadPixels` 回读到 CPU、重新逐像素转色，再交给 ModernUI；还存在每帧日志输出。当前入口不再创建该 Fragment 或 offscreen renderer，不再使用像素回读路径。

新预览仅在选择场景时计算一次节点实例和世界包围盒、上传一次 VBO/EBO。后续帧使用 OpenGL 三角形绘制，矩阵和材质为 uniform；不在每帧遍历顶点、重新解析模型、重建三角形或复制预览像素。只缓存当前所选场景，切换、替换、删除和关闭时释放其网格、shader 和自有白色纹理。实际材质图像复用世界/物品的 `ModelTextureCache`，由统一资源生命周期管理，避免在预览中重复解码。

基础颜色支持每网格材质、顶点色、材质实际指定的嵌入图像，以及可解析的磁盘/资源包相对纹理路径。无贴图时使用白色纹理乘材质色。当前是固定工作室光照，不执行 PBR、游戏光照、节点材质或整合包 shader。透明材质单独在不透明之后绘制，但交叠透明表面不是逐像素正确排序。

预览在主帧缓冲中的专用 viewport/scissor 内绘制；绘制前刷新 GUI 批次，绘制后恢复程序、VAO、buffer、纹理、视口、裁剪、深度、混合和背面剔除状态。不会修改共享 scene 的变换、材质或当前世界的动画状态。

## 验证

`PreviewCameraTest` 覆盖不同尺寸/宽高比的自动适配、极端输入和拖拽恢复；`PreviewSceneDataTest` 比较 CIWS 的 STATIC/DYNAMIC 包围盒并检查重复网格实例；`LoadedModelCatalogTest` 检查别名去重、筛选和稳定快照。根任务统一执行编译、测试与客户端检查，本模块不自行并发运行 Gradle。

OpenGL 状态、鼠标交互和真实画面仍需要客户端验收；这些纯数据测试不构成 GPU 兼容认证。

本轮主线已在 Windows x64 / RTX 4060 / OpenGL 4.6 客户端执行七场景截图及一次完整资源重载，检查实际贴图和视角输入。复现方法和证据路径见 [集成记录](LOOKDEV_INTEGRATION.md#real-client-smoke)。这不替代其他驱动、交叠透明或光影包的验证。
